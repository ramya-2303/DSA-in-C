# Graph Programs in C

This folder contains **graph traversal programs written in the C programming language**.  
These programs demonstrate fundamental graph traversal techniques using **Breadth-First Search (BFS)** and **Depth-First Search (DFS)**.

## Files in this Folder

- **BFS_traversal.c**  
  Implements **Breadth-First Search (BFS)** traversal of a graph.

- **DFS_traversal.c**  
  Implements **Depth-First Search (DFS)** traversal of a graph.

- **DFS_Utilities.c**  
   Contains **utility functions** for graph operations such as:
  - Checking whether an **edge exists** between two vertices  
  - Verifying if a **connection is present or not**  
  - Supporting DFS traversal logic


## Concepts Covered

- Graph representation  
- Breadth-First Search (BFS)  
- Depth-First Search (DFS)  
- Graph traversal techniques  


## To Compile and Run
gcc filename.c -o output
./output
