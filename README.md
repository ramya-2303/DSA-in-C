# Data Structures and Algorithms in C

This repository contains implementations of **Data Structures and Algorithms (DSA)** using the **C programming language**.  
The purpose of this project is to strengthen core DSA concepts through hands-on coding .

# Folder Details

- **Array**  
  Programs related to array operations and problems.

- **LinkedLists**  
  Implementation of linked list data structures. (menu driven code)

- **Stack**  
  Stack implementation and applications like parenthesis matching.

- **Queue**  
  Queue data structure programs.

- **Trees**  
  Binary trees and related algorithms.

- **Graph**  
  Graph representations and traversal algorithms such as DFS and BFS.

- **Hashing**  
  Hashing techniques and rehashing implementation.

- **Heap**  
  Min heap implementation.

# Technologies Used
- Programming Language: C
- Compiler: GCC
- Platform: Linux / Windows
