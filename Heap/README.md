# Heap Implementation in C

This folder contains C programs that demonstrate **Heap data structures** and their operations.  
Both **Min Heap** and **Max Heap** implementations are included for learning and practice purposes.

## Files in this Folder

- **heap_operation.c**  
  Contains common heap operations such as:
  - Insertion
  - Deletion
  - Heapify
  - Display of heap elements

- **max_heap.c**  
  Implements a **Max Heap**, where the parent node is always greater than or equal to its child nodes.

- **min_heap.c**  
  Implements a **Min Heap**, where the parent node is always smaller than or equal to its child nodes.

## How to Compile and Run

Use gcc to compile any file:
gcc heap_operation.c -o heap_operation
./heap_operation
