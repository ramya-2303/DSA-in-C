# Tree Data Structures in C

This folder contains C programs that implement different **Tree data structures** and their operations, with a primary focus on **Binary Search Trees (BST)** and **Binary Trees**.

## Files in this Folder

- **bst_insertion.c**  
  Implementation of **insertion operation** in a Binary Search Tree.

- **bst_search.c**  
  Program to **search for an element** in a Binary Search Tree.

- **bst_deletion.c**  
  Implementation of **deletion operation** in a Binary Search Tree, handling all cases.

- **bst_check.c**  
  Program to **check whether a given tree is a valid Binary Search Tree**.

- **tree_traversal.c**  
  Demonstrates different **tree traversal techniques**:
  - Inorder
  - Preorder
  - Postorder

- **expression_tree.c**  
  Implementation of an **Expression Tree** to evaluate or represent arithmetic expressions.

- **threaded_binary_tree.c**  
  Implementation of a **Threaded Binary Tree** to enable traversal without recursion or stack.

## How to Compile and Run

Use gcc to compile any file:
gcc bst_insertion.c -o bst_insert
./bst_insert
