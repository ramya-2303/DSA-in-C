# Array Programs in C

This folder contains **basic array programs written in the C programming language**.

## Files in this Folder

- **array_operations.c**  
  Performs basic array operations such as **insertion, deletion, and traversal**.

- **linear_search.c**  
  Searches an element using the **Linear Search** technique.

- **binary_search.c**  
  Searches an element using **Binary Search** (array must be **sorted**).


## Concepts Covered

- Arrays  
- Traversing an array (insertions and deletions)
- Linear Search  
- Binary Search  

## How to Compile and Run

gcc filename.c -o output
./output
